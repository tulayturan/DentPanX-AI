# Dataset Notice

DentPanX-AI was developed using the MOPG-7 dental panoramic radiograph dataset.

The full source dataset is not redistributed in this repository. The repository contains split assignments, metadata, evaluation materials, derived research outputs, and documentation required to reproduce the reported workflow.

Users must obtain the source dataset from its official repository and comply with the license and usage terms applicable to the dataset version they obtain.

The manuscript documents the frozen dataset version used in the study. Because repository licensing and version availability may change over time, users should verify the official dataset record before reuse or redistribution.

A minimal test case may identify a source-image filename and checksum for software verification. Redistribution of any source image should occur only when permitted by the applicable dataset terms.

The dataset-defined labels and annotations are used for research evaluation and do not constitute an independent clinical reference standard established by DentPanX-AI.
